# Admin 管理后台

## 功能概述

Admin管理后台提供了完整的系统管理功能，包括字典管理等核心功能。

## 主要特性

### 1. 侧边栏导航
- ✅ 响应式侧边栏菜单
- ✅ 可折叠/展开
- ✅ 面包屑导航
- ✅ 路由高亮显示

### 2. 字典管理
- ✅ 字典列表展示（支持分页、搜索）
- ✅ 字典创建和编辑
- ✅ 字典启用/禁用状态切换
- ✅ 字典删除（带确认提示）
- ✅ 版本号自动管理（后端维护）
- ✅ 创建时间和更新时间显示

### 3. 字典项管理（新功能）
- ✅ **列表样式展示字典项**
- ✅ **拖拽排序功能**
- ✅ **动态添加/删除字典项**
- ✅ 字典项启用/禁用状态
- ✅ 字典项验证（标签、值不能为空，值不能重复）
- ✅ 实时编辑功能

## 访问方式

### URL路径
- 管理后台首页：`/admin`
- 仪表盘：`/admin/dashboard`
- 字典管理：`/admin/dict`
- 新建字典：`/admin/dict/new`
- 编辑字典：`/admin/dict/:code`

### 从主应用访问
在浏览器地址栏输入：`http://localhost:3001/admin`

## 新增功能详解

### 1. 侧边栏菜单
- 使用Ant Design Layout组件
- 支持折叠/展开切换
- 菜单项包括：仪表盘、字典管理
- 自动根据当前路由高亮对应菜单

### 2. 字典项列表样式
- 替换原有的表格展示为卡片列表
- 每个字典项显示为独立的卡片行
- 包含标签、值、状态等字段
- 支持内联编辑

### 3. 拖拽排序
- 使用 @dnd-kit 库实现
- 支持鼠标拖拽和键盘操作
- 拖拽时有视觉反馈
- 自动更新排序号

### 4. 动态添加字典项
- 列表底部有"新增字典项"按钮
- 点击后在列表末尾添加新行
- 新行默认启用状态
- 自动分配排序号

### 5. 时间字段显示
- 字典列表增加创建时间和更新时间列
- 字典详情页显示创建时间和更新时间
- 使用 dayjs 格式化时间显示

## 技术实现

### 核心依赖
```json
{
  "@dnd-kit/core": "^6.3.1",
  "@dnd-kit/sortable": "^10.0.0", 
  "@dnd-kit/utilities": "^3.2.2",
  "dayjs": "^1.11.15"

```

### 组件结构
```
Admin/
├── AdminLayout.tsx          # 管理后台布局
├── AdminRoutes.tsx          # 路由配置
└── DictManagement/
    ├── DictList.tsx         # 字典列表（已更新）
    ├── DictDetail.tsx       # 字典详情/编辑（新增）
    ├── DictDetailModal.tsx  # 字典详情弹窗（已更新）
    ├── DictFormModal.tsx    # 字典表单弹窗
    └── DraggableDictItemList.tsx  # 可拖拽字典项列表（新增）
```

### 数据流
1. **字典列表** → 点击编辑 → **字典详情页**
2. **字典详情页** → 编辑字典项 → **拖拽排序组件**
3. **拖拽排序组件** → 数据变更 → **回调更新父组件**

## 使用说明

### 1. 访问管理后台
在浏览器中访问 `/admin` 路径

### 2. 字典管理
- 在侧边栏点击"字典管理"
- 查看字典列表，支持搜索和分页
- 点击"新增字典"创建新字典
- 点击编辑图标进入字典详情页

### 3. 字典项配置
- 在字典详情页可以看到字典项列表
- 拖拽左侧的拖拽图标可以调整顺序
- 点击"新增字典项"添加新项
- 直接在输入框中编辑标签和值
- 使用开关控制启用/禁用状态
- 点击删除按钮移除字典项

### 4. 保存更改
- 编辑完成后点击右上角"保存"按钮
- 系统会验证数据完整性
- 保存成功后返回字典列表

## 注意事项

1. **版本号管理**：版本号由后端自动维护，每次修改字典时自动递增
2. **字典项排序**：通过拖拽自动更新 sort 字段
3. **数据验证**：
   - 字典编码必须唯一，只能包含大写字母、数字和下划线
   - 字典项的值在同一字典内不能重复
   - 字典项的标签和值不能为空
4. **权限控制**：所有 API 请求都需要有效的认证 token
