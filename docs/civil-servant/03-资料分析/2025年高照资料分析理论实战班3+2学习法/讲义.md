## 一、4个常用速算小技巧

### 1. 一个数×1.5

等于这个数+本身的一半。

- 示例1：\(120×1.5 = 120 + 60 = 180\)
- 示例2：\(124×1.5 = 124 + 62 = 186\)

### 2. 一个数×1.1与×0.9

- （1）一个数×1.1，等于这个数错位相加。
  - 示例1：\(120×1.1 = 120 + 12 = 132\)
  - 示例2：\(124×1.1 = 124 + 12.4 = 136.4\)
- （2）一个数×0.9，等于这个数错位相减。
  - 示例1：\(120×0.9 = 120 - 12 = 108\)
  - 示例2：\(124×0.9 = 124 - 12.4 = 111.6\)

### 3. 一个数÷5、÷25、÷125

- 一个数÷5，等于这个数×2，小数点移一位。
- 一个数÷25，等于这个数×4，小数点移两位。
- 一个数÷125，等于这个数×8，小数点移三位。
- 计算示例：
  - \(\frac{24}{5} = 24×2÷10 = 48÷10 = 4.8\)
  - \(\frac{36}{5} = 36×2÷10 = 72÷10 = 7.2\)
  - \(\frac{24}{25} = 24×4÷100 = 96÷100 = 0.96\)
  - \(\frac{36}{25} = 36×4÷100 = 144÷100 = 1.44\)
  - \(\frac{24}{125} = 24×8÷1000 = 192÷1000 = 0.192\)
  - \(\frac{36}{125} = 36×8÷1000 = 288÷1000 = 0.288\)

### （一）分数拆分思想

通过**化1法、化半法、凑整法**将分数拆分为易计算的部分，简化运算：

- 化1法：将分子拆分为与分母相等的数加余数，如 \(\frac{145}{142} = \frac{142+3}{142} = 1 + \frac{3}{142} \approx 1 + 2\%\)。
- 化半法：将分子拆分为分母一半的数加余数，如 \(\frac{74}{142} = \frac{71+3}{142} = 50\% + \frac{3}{142} \approx 50\% + 2\%\)。
- 凑整法：通过拆分使计算更接近整数，减少误差。

### （二）比重与增长结合的计算

涉及“整体×比重”“部分÷整体”的计算时，结合**百化分、拆分法**快速求解，同时注意同比增长的影响，通过“基期×(1+增长率)”推导现期。

## 二、例题解答

### 【例1】

\(\frac{254}{248}\)
A.100.4%
B.101.4%
C.102.4%
D.103.4%

**解答**：选C。

**解析**：
用分数拆分思想（化1法）：
\(\frac{254}{248} = \frac{248+6}{248} = 1 + \frac{6}{248} \approx 1 + 2.4\% = 102.4\%\)，对应选项C。

### 【例2】

\(\frac{248}{254}\)
A.95.6%
B.96.6%
C.97.6%
D.98.6%

**解答**：选C。

**解析**：
用分数拆分思想（凑整法）：
\(\frac{248}{254} = 1 - \frac{6}{254} \approx 100\% - 2.4\% = 97.6\%\)，对应选项C。

### 【例3】

\(\frac{1660.49}{3480.70}\)
A.45.5%
B.46.2%
C.47.7%
D.48.7%

**解答**：选C。

**解析**：
用凑整法拆分：
\(\frac{1660.49}{3480.70} \approx \frac{1740 - 80}{3480} = 50\% - \frac{80}{3480} \approx 50\% - 2.3\% = 47.7\%\)，对应选项C。

### 【例2】（2024联考）

2022年我国废有色金属中废铅回收重量约为：
A.261万吨
B.275万吨
C.285万吨
D.291万吨

**解答**：选C。

**解析**：

- 2021年废有色金属中废铅占比：\(100\% - 51.93\% - 10.16\% - 17.88\% = 20.03\%\)
- 2021年废铅回收重量：\(1348×20.03\% \approx 269.6\)万吨
- 2022年废铅回收重量（同比增长5.56%）：\(269.6×(1 + 5.56\%) \approx 269.6 + 269.6×\frac{1}{18} \approx 269.6 + 15 = 284.6\)万吨，对应选项C。

### 【例3】（2024天津事业单位）

2022年东部地区完成互联网业务收入为（）亿元。
A.13248
B.13325
C.13478
D.13562

**解答**：选A。

**解析**：
东部地区收入 = 全国总收入×比重 = \(14590×90.8\%\)
拆分计算：
\(14590×90\% = 13131\)，\(14590×0.8\% = 116.72\)
总和：\(13131 + 116.72 \approx 13247.72\)，与选项A（13248）一致。
