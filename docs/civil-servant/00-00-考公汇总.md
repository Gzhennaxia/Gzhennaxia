#### 基础阶段重点

1. 拉思维导图
2. 做好母体
3. 倍速（缩短上课时间、拉长学习时长）
4. 先学言语、判断、资料分析三大板块
5. 数量：只学考频高且自己觉得简单的
6. 常识：午休时磨耳朵（追梦人）
7. 政治理论：累了时学

### 刷题阶段

1. 分前期和后期两个阶段，前期注重刷题的题量，把量提上来，不要过于重视复盘，等各个板块题量刷够300~500题后再重视复盘
2. 前期的复盘：能给自己讲明白，ABCD为什么对为什么错就可以
3. 前期不要卡时间
4. 后期的复盘：为什么做错，同类型的题多刷

### 套题阶段

1. 优先刷真题，3~5年的真题
2. 刷题顺序：国考-》本省省考-》多省联考
3. 不断调整各个板块的做题顺序和时间占比
4. 复盘：微观上分析每道错题的原因，宏观上分析各个板块的正确率和时间占比
5. 模考分数-3~5分=真实成绩
