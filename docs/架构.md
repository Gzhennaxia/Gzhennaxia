# 架构

- 项目架构说明
- 技术栈及对应的版本信息

## 前端

- **React 18** - 前端框架
- **Vite 5** - 构建工具，支持热重载
- **TypeScript** - 类型安全
- **Ant Design 5** - UI 组件库
- **Day.js** - 日期处理
- **Axios** - HTTP 客户端

## 后端

- **Maven** - 依赖管理
- **Spring Boot 3.2.9** - 主框架
- **MyBatis-Plus 3.5.14** - ORM 框架
- **Caffeine 3.1.8** - 本地缓存

## 数据库

- **PostgreSQL** - 主数据库
