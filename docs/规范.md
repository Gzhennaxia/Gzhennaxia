pojo

1. request, 用于接收前端传参，只能在controller，不可跨层
2. dto，用于各层直接的跨层
3. entity，实体类，字段对应表结构的字段
4. vo，用于返回前端，同request，只能在controller，不可跨层

对于一个接口，会从 request，到 dto，再到entity，再到 vo，再到前端


pageRequest 示例

```json
{
  "pageNo": 1,
  "pageSize": 10,
  "query": {
    "id": 123,
    "type_like": "EAD",
    "createTime_lte": "2025-08-28 18:32:26",
    "createTime_gte": "2025-08-28 18:32:26"
  },
  "sort": {
    "createTime": "desc"
  }
}
```

response 示例

```json
{
  "status": 200,
  "message": "success",
  "data": {
    
  }
}
```

定义统一的响应体结构，并通过 全局拦截 / 处理机制 自动封装所有接口的返回结果（包括正常响应和异常响应），避免手动重复编码。
