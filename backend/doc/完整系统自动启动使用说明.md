# 完整系统自动启动功能使用说明

## 功能概述

本功能实现了IB Gateway、前端项目和后端应用的协调启动，并自动打开浏览器访问相关页面，为用户提供一键启动的完整解决方案。

## 🚀 主要特性

- ✅ **一键启动**：Spring Boot应用启动后自动启动所有相关服务
- ✅ **智能检测**：IB Gateway和前端项目启动状态智能检测
- ✅ **自动打开浏览器**：
  - IB Gateway启动成功后自动打开 https://localhost:5000
  - 前端启动成功后延迟3秒自动打开 http://localhost:3000
- ✅ **并行/顺序启动**：支持并行启动和顺序启动两种模式
- ✅ **完整的REST API**：提供管理所有服务的API接口
- ✅ **优雅关闭**：应用关闭时自动停止所有服务

## 🔧 配置说明

### 完整配置示例

```yaml
# Interactive Brokers API配置
ib:
  accountId: U16166218
  api:
    gateway:
      url: https://localhost:5000
  gateway:
    enabled: true  # 是否在应用启动时自动启动Gateway
    path: D:/SOFTERWARE/clientportal.beta.gw  # Gateway安装路径
    auto:
      open:
        browser: true  # 是否自动打开浏览器
    startup:
      timeout: 30  # 启动超时时间（秒）

# 前端服务配置
frontend:
  enabled: true  # 是否启用前端自动启动
  path: frontend  # 前端项目路径（相对于后端项目根目录）
  url: http://localhost:3000  # 前端访问地址
  auto:
    open:
      browser: true  # 是否自动打开浏览器
  startup:
    timeout: 60  # 启动超时时间（秒）

# 启动协调器配置
startup:
  coordinator:
    enabled: true  # 是否启用启动协调器
    parallel: true  # 是否并行启动（true：同时启动，false：顺序启动）
```

### 配置参数详解

#### IB Gateway配置
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `ib.gateway.enabled` | boolean | true | 是否自动启动Gateway |
| `ib.gateway.path` | string | D:/SOFTERWARE/clientportal.beta.gw | Gateway安装路径 |
| `ib.gateway.auto.open.browser` | boolean | true | 是否自动打开浏览器 |
| `ib.gateway.startup.timeout` | int | 30 | 启动超时时间（秒） |

#### 前端服务配置
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `frontend.enabled` | boolean | true | 是否自动启动前端项目 |
| `frontend.path` | string | frontend | 前端项目路径 |
| `frontend.url` | string | http://localhost:3000 | 前端访问地址 |
| `frontend.auto.open.browser` | boolean | true | 是否自动打开浏览器 |
| `frontend.startup.timeout` | int | 60 | 启动超时时间（秒） |

#### 启动协调器配置
| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `startup.coordinator.enabled` | boolean | true | 是否启用启动协调器 |
| `startup.coordinator.parallel` | boolean | true | 启动模式（并行/顺序） |

## 🎯 启动流程

### 并行启动模式（推荐）

1. **启动Spring Boot应用**
2. **同时启动**：
   - IB Gateway（后台启动，智能检测状态）
   - 前端项目（Vue3 + Vite项目）
3. **自动打开浏览器**：
   - IB Gateway启动成功 → 立即打开 https://localhost:5000
   - 前端启动成功 → 延迟3秒打开 http://localhost:3000

### 顺序启动模式

1. **启动Spring Boot应用**
2. **第一步**：启动IB Gateway并自动打开浏览器
3. **第二步**：启动前端项目并自动打开浏览器

## 🔌 REST API 接口

### 1. 获取所有服务状态

```http
GET /api/startup/status
```

**响应示例：**
```json
{
  "gatewayRunning": true,
  "frontendRunning": true,
  "allServicesRunning": true,
  "timestamp": 1748520328000
}
```

### 2. 重启所有服务

```http
POST /api/startup/restart-all
```

### 3. 前端项目管理

```http
# 启动前端
POST /api/startup/frontend/start

# 停止前端
POST /api/startup/frontend/stop

# 重启前端
POST /api/startup/frontend/restart

# 获取前端状态
GET /api/startup/frontend/status
```

### 4. 获取启动指南


## 🛠️ 使用方式

### 方式一：完全自动（推荐）

1. **配置项目**：确保所有配置正确
2. **启动应用**：运行Spring Boot应用
3. **等待自动启动**：系统会自动启动所有服务并打开浏览器
4. **完成登录**：在IB Gateway页面完成登录
5. **使用系统**：前端系统会自动打开

### 方式二：API管理

```bash
# 检查服务状态
curl http://localhost:8080/api/startup/status

# 重启所有服务
curl -X POST http://localhost:8080/api/startup/restart-all

# 获取启动指南
curl http://localhost:8080/api/startup/guide
```

## 🚨 故障排除

### 1. IB Gateway启动失败
- 检查Gateway安装路径是否正确
- 确认`bin/run.bat`文件存在
- 检查Java环境是否配置正确

### 2. 前端项目启动失败
- 确认前端项目路径正确
- 检查Node.js和npm是否安装
- 确认`package.json`文件存在
- 尝试手动执行`npm install`

### 3. 浏览器无法自动打开
- 检查操作系统是否支持Desktop API
- 手动访问相关URL
- 检查防火墙设置

### 4. 端口冲突
- 修改相关配置中的端口号
- 检查端口是否被其他程序占用

## 📈 性能优化建议

1. **SSD硬盘**：使用SSD可显著提升启动速度
2. **内存充足**：建议至少8GB内存
3. **并行启动**：使用并行模式可节省启动时间
4. **预热缓存**：首次启动后，后续启动会更快
